## ADDED Requirements

### Requirement: ソースデータ出典（attribution）の表示
サイトは、路線・地点・都道府県境界の各PMTilesソースについて、データ出典（国土数値情報／国土交通省）を示すattribution文字列を設定しなければならない（SHALL）。attribution文字列は、MapLibre GL JSのAttributionControlを通じて地図上に表示されなければならない（SHALL）。

#### Scenario: 出典表示の確認
- **WHEN** ユーザーが地図サイトを開く
- **THEN** 地図のAttributionControlに、路線・地点・都道府県境界データの出典（国土数値情報／国土交通省）を示す文言が表示される

### Requirement: 路線クリック時のポップアップ表示
ユーザーが路線レイヤーの地物をクリックすると、その路線の属性（路線名・路線種別・車線数）を表示するポップアップが表示されなければならない（SHALL）。路線種別区分は、コード値ではなく人が読める種別名で表示しなければならない（SHALL）。

#### Scenario: 路線クリックでのポップアップ表示
- **WHEN** ユーザーが地図上の路線をクリックする
- **THEN** クリックした路線の属性（路線名・路線種別名・車線数）を表示するポップアップが、クリック位置に表示される

#### Scenario: 路線以外をクリックした場合
- **WHEN** ユーザーが路線・地点いずれの地物にも該当しない地図上の位置をクリックする
- **THEN** ポップアップは表示されない。既にポップアップが表示されていた場合は閉じる

## MODIFIED Requirements

### Requirement: 地点クリック時のポップアップ表示
ユーザーが地点（IC・JCT等）レイヤーの地物をクリックすると、その地物の属性を表示するポップアップが表示されなければならない（SHALL）。ポップアップには、地点名・地点種別に加え、その地点に接続する路線の車線数を表示しなければならない（SHALL）。1つの地点に車線数の異なる複数の路線が接続する場合（主にジャンクション）は、接続するすべての路線の車線数を表示しなければならない（SHALL）。

#### Scenario: 地点クリックでのポップアップ表示
- **WHEN** ユーザーが地図上の地点マーカーをクリックする
- **THEN** クリックした地点の属性（地点名・地点種別・接続する路線の車線数）を表示するポップアップが、その地点の位置に表示される

#### Scenario: 複数路線が接続する地点でのポップアップ表示
- **WHEN** ユーザーが車線数の異なる複数の路線が接続する地点（ジャンクション等）のマーカーをクリックする
- **THEN** ポップアップには、接続するすべての路線の車線数が表示される

#### Scenario: 地点以外をクリックした場合
- **WHEN** ユーザーが地点マーカー以外の地図上の位置をクリックする
- **THEN** ポップアップは表示されない。既にポップアップが表示されていた場合は閉じる
