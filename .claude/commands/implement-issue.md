GitHub Issue `$ARGUMENTS` の内容を確認し、Issueの要件を満たす実装を行ってください。

以下のルールを遵守してください。

* 対象Issueの内容、受け入れ条件、依存Issueを最初に確認すること
* 対象Issueの実装に必要な変更だけを行うこと
* 実装前に既存コードと関連テストを確認すること
* 必要に応じてテストを追加・修正すること
* 実装後、関連するテストを実行し、成功を確認すること
* 適切なブランチを作成して作業すること
* 変更内容をコミットすること
* リモートリポジトリへpushすること
* Pull Requestを作成すること
* Pull Requestの本文に対象Issueを自動クローズする `Closes #<Issue番号>` を必ず含めること
* Pull Requestには変更内容、テスト内容を記載すること
* Pull Request作成まで実施すること
* `main` ブランチへのマージは絶対に実施しないこと
* PR作成後はそこで作業を終了すること
